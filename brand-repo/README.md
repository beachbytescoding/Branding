# Beach Bytes — Brand Assets

Hosted at **https://beachbytescoding.github.io/Branding/brand-repo/**

Link to files by path, e.g.
`https://beachbytescoding.github.io/Branding/brand-repo/gmail/bb-signature-white.gif`

## Files

| Folder | Contents |
|---|---|
| `svg/` | Master mark (`bb-mark.svg`) plus white, black, mono, flat, ripples and icon-tile variants |
| `png/` | Raster logos (full lockup, small, small mark) and stacked lockup `bb-lockup-stacked*.png` (transparent, white, navy, 600 px) |
| `gmail/` | Animated email-signature GIFs: `bb-signature-*` 395 × 84 px, and `bb-signature-tagline-*` 484 × 113 px with tagline. `white` for light backgrounds, `navy` for dark |
| `windows/` | `bb-icon.ico` — desktop shortcut icon, 16–256 px |

Use SVG wherever possible. Don't redraw, recolour, stretch or rotate the mark.

## Type

Wordmark: **Beach Bytes** with a blinking sand-coloured cursor.
Typeface: **Fredoka SemiBold (600)**, free on Google Fonts. "Beach" in Navy, "Bytes" in Lake 1, cursor in Sand 1 (on navy: White / Lake 3 / Sand 2).

## Tagline

"Don’t just learn to code, code to learn." — Fredoka Medium (500)
Supporting line: CRITICAL THINKING • ATTENTION TO DETAIL • PROBLEM SOLVING — Outfit Medium (500), uppercase, justified to the tagline width, Sand dots.

## Mark

Cresting wave with overhang lip over a sand shoreline. ViewBox 256 × 170 (≈ 1.61 : 1).
Clear space: at least the height of the lip on all sides. Minimum size: 24 px tall on screen.
